# 进程调度模拟系统

## 项目简介

本项目是一个 C++ 操作系统课程设计项目，用于模拟常见进程调度算法的执行过程。程序采用 **C++17 + Win32 API + GDI** 编写，是 Windows 原生图形窗口程序，不依赖 Qt、MFC、EasyX 等额外图形库，适合在 Windows + VS Code + MinGW 环境中编译运行。

## 功能介绍

程序主窗口标题为“进程调度模拟系统”，支持以下功能：

- 输入进程名、到达时间、服务时间、优先级。
- 添加进程、删除选中进程、清空进程。
- 通过下拉框选择 6 种调度算法。
- 为 RR 时间片轮转算法设置时间片。
- 显示“算法说明”区域，选择不同算法时自动显示简短说明。
- 点击“开始调度”后显示：
  - 调度顺序。
  - 每个进程的进程名、到达时间、服务时间、优先级、开始时间、完成时间、周转时间、带权周转时间。
  - 平均周转时间和平均带权周转时间。
  - 使用 GDI 绘制的甘特图；抢占式算法和 RR 中同一进程可多次出现。
- 基本输入检查：
  - 进程名不能为空。
  - 到达时间不能小于 0。
  - 服务时间必须大于 0。
  - RR 时间片必须大于 0。

## 支持的调度算法

1. **FCFS 先来先服务**：非抢占式，按照进程到达时间先后顺序执行，到达时间相同则按输入顺序执行。
2. **SJF 非抢占式短作业优先**：CPU 空闲时，从已经到达的进程中选择服务时间最短的进程；进程一旦开始运行就一直运行到完成。
3. **SRTF 抢占式短作业优先**：又称最短剩余时间优先；每个时间单位选择剩余运行时间最短的进程，新到达的短作业可能抢占当前进程。
4. **Priority 非抢占式优先级调度**：优先级数字越小优先级越高；CPU 空闲时选择已到达进程中优先级最高者执行，执行后不被打断。
5. **Preemptive Priority 抢占式优先级调度**：每个时间单位选择优先级最高的进程；更高优先级进程到达时可以抢占当前进程。
6. **RR 时间片轮转**：按照到达时间进入就绪队列，每个进程最多运行一个用户指定的时间片，未完成则重新进入队尾。

## 技术栈

- 编程语言：C++17
- 图形界面：Win32 API
- 图形绘制：GDI
- 推荐编译器：MinGW-w64 g++
- 推荐编辑器：VS Code

## 环境搭建方法

1. 安装 Windows 系统。
2. 安装 VS Code。
3. 安装 MinGW-w64，并确保 `g++` 已加入系统 `PATH`。
4. 在终端中执行以下命令检查环境：

```bash
g++ --version
```

如果能看到 g++ 版本信息，说明编译环境配置成功。

## 编译运行方法

在项目根目录打开 PowerShell、CMD 或 VS Code 终端，执行：

```bash
g++ -std=c++17 -municode src/main.cpp -o process_scheduler.exe -mwindows -lcomctl32
```

编译成功后运行：

```bash
./process_scheduler.exe
```

说明：

- `-std=c++17`：启用 C++17 标准。
- `-municode`：使用 Unicode 入口函数 `wWinMain`。
- `-mwindows`：生成 Windows 图形界面程序。
- `-lcomctl32`：链接公共控件库，用于列表控件。

## 展示效果说明

程序窗口主要分为四部分：

1. **输入区**：位于窗口上方，用于录入进程信息、选择调度算法和输入时间片。
2. **算法说明区**：位于算法选择框右侧，选择不同算法时显示对应算法的简短说明。
3. **列表区**：左侧显示输入进程信息，右侧显示调度后的完整计算结果。
4. **甘特图区**：位于窗口下方，用不同颜色的矩形展示进程运行片段，矩形中显示进程名，矩形下方显示开始时间和结束时间；连续执行同一进程的相邻时间片会合并显示，避免图形过碎。
